# Screen Mark 설계

개인용 Chrome Manifest V3 확장 프로그램. 사용자가 2026-10-21 캡처 도구 제작을 요청했고, 사각형 표시와 원형 숫자 라벨을 추가하도록 확정함.

## 선택한 방식

단순 캡처형, 로컬 편집형, 클라우드 공유형 중 로컬 편집형을 사용한다. 서버와 계정 없이 브라우저 안에서 처리하며 외부 네트워크로 이미지를 보내지 않는다.

## 사용 흐름

확장 팝업에서 현재 화면 또는 스크롤 전체 페이지를 선택한다. 캡처 후 편집 탭이 열린다. 파일을 직접 열어 편집할 수도 있다. 2026-10-21 사용자 추가 지시에 따라 캡처는 이 두 가지만 제공한다. AI 작업에서 붙여 넣는 사용이 많으므로 클립보드 복사를 주 버튼으로 두고 Ctrl+C 단축키를 제공한다. 파일 저장은 보조 버튼으로 제공한다.

사각형, 원형 숫자 라벨, 화살표, 텍스트, 모자이크, 자르기를 제공한다. 번호 라벨은 클릭할 때마다 자동 증가하며 시작 번호도 지정할 수 있다. 선택 도구로 표시를 이동하거나 삭제한다. 색상과 선 굵기를 지정하고 실행 취소와 다시 실행을 지원한다. PNG 저장과 클립보드 복사에는 표시가 합성된다.

## 구조와 데이터

Vanilla JavaScript ES modules, Canvas 2D, service worker, IndexedDB. 캡처 이미지는 확장 내부 IndexedDB에 임시 보관하며 편집 탭을 새로고침해도 복원한다. 최근 캡처 보관함은 제공하지 않고 하루가 지난 작업은 새 캡처 시 정리한다. 파일 읽기는 PNG/JPEG/WebP만 허용하며 픽셀 상한을 적용한다. 외부 코드, CDN, 분석 스크립트는 쓰지 않는다.

전체 페이지는 세로 스크롤 캡처를 합성한다. 원래 스크롤과 변경한 스타일은 finally에서 복원한다. 탭 전환, 가로로 넘치는 페이지, 과도한 이미지 크기는 오류로 알린다. 무한 스크롤과 내부 스크롤 패널은 현재 로드된 본문만 대상으로 한다.

## 검증

좌표 변환, 역방향 드래그, 번호 증가, 이동, 잘라내기, 실행 취소를 Node 테스트로 확인한다. 별도 Chromium 프로필에서 실제 확장을 로드해 캡처, 원형 숫자, 사각형, PNG 결과 픽셀, 새로고침 복원을 확인한다. 클립보드 API와 권한은 실행 환경에 따라 검증 범위를 구분해 보고한다.
