# 사각형 자동 번호 구현 계획

요청: 사각형을 그리면 원형 번호 라벨이 자동으로 붙는다.

구현 방향은 사각형 도구의 기본 켜짐 체크박스다. 항상 자동으로 붙이는 방식은 번호 없는 박스를 만들 수 없고, 별도 도구를 추가하는 방식은 도구 선택을 늘린다. 체크박스는 기존 사각형·번호 라벨 도구와 함께 사용할 수 있다.

사각형을 완성할 때 기존 사각형과 번호 shape를 같은 commit으로 추가한다. 번호는 기존 다음 번호·색상·크기를 사용하고, 정규화한 박스 왼쪽 위를 기준으로 현재 이미지나 잘린 영역 안에 배치한다. 실행 취소·다시 실행은 둘을 한 번에 처리하며, 추가 후에는 기존 도구로 각각 선택·이동·삭제할 수 있다. 이미 만든 사각형에는 소급 적용하지 않는다. 체크 상태는 해당 편집 탭의 설정으로 두며 새로 열면 켜짐이다.

1. 기존 브라우저 검사에 자동 번호 기본 켜짐, 원자적 실행 취소, 연속·수동 번호 공유, 체크 해제, 저장·새로고침·PNG 검사를 먼저 추가하고 기존 코드에서 실패하는지 확인한다.
2. 좌표 계산의 가장자리·잘린 영역·작은 이미지 회귀 검사를 먼저 만들고 실패를 확인한 뒤 순수 좌표 함수를 구현한다. 기존 렌더·저장 구조는 사용한다.
3. 체크박스와 일괄 추가를 연결한다. 기존 수동 도구 검사는 체크를 끈 상태에서 유지한다.
4. 단위·브라우저 검사를 실행하고 실제 별도 Chrome에서도 새 기능을 확인한다. 코드·입력 경계 리뷰 후 설명·실제 사용 이미지·패키지를 갱신한다.
5. v1.0.5로 GitHub에 반영하고 공개 소스·ZIP 일치를 확인한다. 설치된 소스 폴더는 확장 새로고침으로 적용한다.
