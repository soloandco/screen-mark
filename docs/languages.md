# Screen Mark 언어 지원

기본값은 영어이며 선택 순서는 English, 한국어, 日本語, Español임. 캡처 메뉴와 편집기, 기존 선택 탭에 같은 언어 선택을 제공함.

- 선택은 확장 프로그램의 브라우저 저장소에 보관함. 열린 확장 탭의 문구도 갱신하며 화면을 다시 로드하지 않음.
- 이미지·사용자 파일명·사용자가 입력한 글자·표시·실행 취소·선택 도구·확대율을 바꾸지 않음. 도구 설명, 상태·오류, 제목, 접근성 라벨도 번역함.
- 실제 페이지 위에 뜨는 영역 선택 안내는 시작 시 언어를 유지함. 언어를 바꾸고 다시 시작하면 새 언어로 안내함.
- 설정을 저장하지 못하면 이전 언어를 유지하고 재시도 문구를 표시함. 알 수 없는 저장값이나 요청 언어는 영어로 처리함.
- 확장 관리 화면의 이름·설명은 Chrome의 언어에 따라 표시함. 앱 안에서 고른 언어는 캡처·편집 화면의 언어임.

## 번역 관리

`extension/i18n.js`에서 언어 순서·영어 기본값·선택 저장·화면 갱신을 관리함. `extension/translations.js`는 한국어 원문을 안정적인 키로 사용하고 영어·일본어·스페인어 번역을 보관함. 순수 모델·저장 모듈의 오류 형식과 Error.name은 유지하며 표시 시 번역함. 알 수 없는 브라우저 오류는 진단 내용을 보존함.

동적 문구는 `{count}`, `{error}` 같은 변수를 사용함. 문구를 추가하면 세 번역의 변수도 일치해야 함. 번역 결과는 textContent나 해당 속성에만 넣으며 HTML로 해석하지 않음. 화면 문구를 고칠 때 사용자 파일명이나 표시 텍스트를 사전에 넣지 않음.

## 검증

`npm test`가 언어 순서, 기본값, 잘못된 설정값, 번역 변수, 저장 실패, 원래 오류 전달, Chrome 메타데이터를 검사함. `npm run test:languages`는 별도 Chrome 프로필에서 네 언어로 실제 캡처·편집·저장·복사를 실행함. 언어를 바꿔도 같은 문서와 revision을 유지하는지 비교함. 새 언어로 영역 선택을 다시 시작하는 경로도 검사함.

일반 브라우저·영역·붙여넣기·저장 안정성 회귀 검사는 `tests/support/language.mjs`로 한국어를 선택해서 기존 동작을 확인함. 언어 전용 검사는 새 프로필의 영어 기본값부터 시작함. 기존 화면 예시 이미지는 촬영 당시 버전의 화면이며 현재 기능은 언어 검사 결과를 기준으로 함.
